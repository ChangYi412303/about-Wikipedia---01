# about-Wikipedia---01

**維基百科本身就是世界的亂源之一，說白話就是世界垃圾平台**

2026年11月24日，我的維基百科使用者頁面「User:張枍」被標上快速刪除模板，理由是「請求快速刪除（CSD G11）」——也就是被認定為廣告宣傳。接著，我收到不限期封禁通知，罪名是「散發廣告／宣傳」。

我寫的不過是自己與《枍奭》一體三架構的說明。沒有叫人買東西，沒有推銷課程，沒有要求別人相信我。結果，就被判定為廣告，頁面準備刪除，帳號無限期封鎖。

這不是個案。這正是維基百科運作邏輯的真實寫照。

一個號稱「自由的百科全書」的平台，任何註冊帳號、甚至匿名IP，都可以改動內容。今天你寫的，明天可能被改成完全相反的說法；今天被認定中立，明天可能被貼上「宣傳」標籤。編輯權掌握在少數活躍管理員與社群共識手裡，而共識本身又高度依賴誰嗓門大、誰人脈多、誰更懂規則遊戲。結果就是：真實性讓位給權力遊戲，公信力讓位給臨時投票。

這樣的東西，怎麼還能被當成可靠知識來源？

維基百科從一開始就埋下結構性缺陷。任何人都能改，意味著任何人都能植入、刪除、扭曲。它不是經過專業審核的知識庫，而是一場永不結束的編輯戰爭。被改壞的內容，往往要等有人發現、有人反駁、有人投票，才能勉強恢復。期間，錯誤資訊已經被搜尋引擎收錄、被媒體引用、被學生當成作業來源。損害已經造成，修正卻永遠慢半拍。

更諷刺的是，它一方面標榜「中立觀點」，另一方面卻對「宣傳」極度敏感。普通人寫自己的思想體系、創作理念，立刻被當成廣告；真正有組織、有資源的公關公司、利益團體，卻能長期用複雜帳號與引用技巧，在條目裡埋下有利於自己的敘事。這不是知識的自由，而是規則被少數人操控的自由。

這樣的平台存在於世界上，本身就是禍害。它讓錯誤資訊合法流通，讓個人名譽可以被匿名帳號任意塗鴉，讓真正想留下思想痕跡的人，被貼上「廣告」標籤後趕出去。它製造爭議、放大對立、消耗公共信任。與其繼續被當成「百科」，不如承認：它更像一個永遠吵不完的論壇，披著百科的外衣。

如果一個知識平台連「誰寫的、為什麼寫、有沒有利益衝突」都無法穩定把關，那它就不配被稱為百科。寧可沒有，也不要這種假裝中立、實則任意可改的亂源。

我把這篇文章放上GitHub與Facebook，不是為了報復，而是為了留下紀錄：當一個普通人只是寫下自己創造的體系，就被快速刪除與無限期封禁時，這個平台已經失去最基本的公正與公信力。

真正有價值的知識，不應該建立在「誰先改誰贏」的遊戲上。

**附錄：維基百科歷來重大爭議與法院相關案例（含尚未最終確定事件）**

1. **Seigenthaler 傳記事件（2005）**  
   匿名編輯在美國記者John Seigenthaler條目中，虛構他涉嫌參與甘迺迪兄弟暗殺。錯誤內容存在數月，引發美國主流媒體對維基可靠性的大規模質疑。

2. **Essjay 爭議（2007）**  
   活躍管理員與仲裁委員Ryan Jordan（Essjay）長期謊稱自己是神學教授、擁有博士學位，並以此影響內容爭議。被《紐約客》揭發後引發身分造假與信任危機。

3. **Bicholim Conflict 偽史事件**  
   一篇完全虛構的「1640–1641年葡萄牙與馬拉塔帝國衝突」文章，在英文維基存活超過五年，甚至一度被評為「優良條目」。

4. **付費編輯與公關滲透**  
   Wiki-PR公司使用大量傀儡帳號為客戶改寫條目；2015年Orangemoody調查揭露數百帳號對企業與名人進行勒索式付費保護。

5. **德國法院判決（2019）**  
   德國法院認定德語維基關於教授Alex Waibel的部分內容構成誹謗（因引用連結失效），要求維基媒體基金會移除相關歷史與內容。

6. **英國Louis Bacon案（2011）**  
   對沖基金經理Louis Bacon取得英國法院命令，要求維基媒體基金會等揭露匿名誹謗者身分。

7. **葡萄牙César do Paço案**  
   法院要求維基媒體基金會移除爭議內容，並交出編輯者資料。平台被認定即使引用公開來源，仍可能須為內容負責。

8. **印度亞洲國際新聞（ANI）訴維基媒體基金會案（2024–2025）**  
   德里高等法院一度要求披露編輯者資訊並刪除相關條目；2025年5月印度最高法院推翻刪除命令。

9. **俄羅斯法院多次罰款**  
   因維基百科記載俄烏戰爭相關內容與官方敘事不符，俄羅斯法院多次對維基媒體基金會開罰。

10. **台灣蔡衍明相關訴訟**  
    蔡衍明對台灣維基媒體協會等提起排除侵害與損害賠償訴訟（含113年度訴字第3051號、114年度訴字第2755號等），法院最終駁回原告請求。

11. **其他重要事件**  
    - 維基媒體基金會訴美國國家安全局（NSA）大規模監控案，最終因國家機密特權結束。  
    - 多起名人／企業因條目內容提告誹謗，部分因美國通訊端正法（CDA Section 230）保護而遭駁回。  
    - 2026年維基百科共同創辦人Larry Sanger因「拉票」行為被禁止編輯。  

以上案例顯示：開放編輯結構長期製造錯誤資訊、名譽損害與法律糾紛。平台一面強調「任何人都能貢獻」，一面卻用內部規則快速刪除與封禁它不喜歡的內容——這正是公信力崩壞的根源。
